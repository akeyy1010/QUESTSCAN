# QUESTSCANの実装構成

## スキャンから書き出しまで

`QUESTSCANApp` が `ScannerModel` を保持し、ホーム、スキャン、3D生成、編集の4画面を切り替えます。UIとRealityKitのEntity生成はメインアクターで行い、カメラ画像のコピー・投影・保存・USDZ生成は専用の直列キューで実行します。

`ARManager` は自動設定を無効にした `ARView` に `ARWorldTrackingConfiguration` を設定します。LiDARメッシュ分類、LiDARメッシュ、検出平面の順に端末能力を判定します。ARSessionのデリゲートキューでMetalバッファのオフセット・ストライド・インデックスを検査し、座標と法線をメートル単位のワールド空間配列へコピーします。ARKitの一時バッファを編集画面やバックグラウンド処理へ直接渡しません。

一時停止と再開では座標系を維持し、新規スキャンまたは明示的リセットだけで座標系を初期化します。スキャン中は端末の自動ロックを抑制し、終了・中止時に解除します。カメラ画像は長辺1,280ピクセル以下のJPEGへ変換し、投影用の内部パラメータは元のカメラ画像サイズで保持します。低電力モードでは写真解像度や処理頻度を抑えます。

`ScanOptions` を `UserDefaults` 内のJSONとして保存し、アプリ起動時に復元します。設定画面は編集中の値を一時保持し、「設定を保存」で適用します。写真の上限（8・16・24・32枚）、自動撮影の3段階感度、写真長辺（960・1,280px）、JPEG品質、形状の面数上限（20k・40k・60k）、ワイヤーフレームを調整できます。感度は撮影間隔・移動距離・角度しきい値の組み合わせです。上限・画質はホワイトリストで検証し、アプリ内のハード上限を超えません。JPEGが1.5MBを超える場合は段階圧縮して写真の記録を維持します。

## カバー率・写真投影

`CoverageEstimator` は保持メッシュから分散サンプリングした三角形を使い、写真の画角・向き・距離・利用可能な深度との整合性から、観測面の写真適合率を推定します。経過時間や移動量だけでスキャン率を増やす実装ではありません。

`TextureProjector` はカメラ姿勢の逆行列と内部パラメータで三角形頂点を元の画像へ投影し、画角外や不適合な深度を除外します。投影面積、正面性、画像中心からの距離等で写真を選び、元アンカー・面分類・写真ごとに部分メッシュを作ります。画像の左上原点を、USD／RealityKitのUV用に上下変換します。生成後のカバー率は、出力三角形の面積に対する実投影面積の割合です。

写真数・メッシュ数・描画グループ数・画像データ量には明示的な上限を設けています。処理用アンカーの間引きや、写真を付けられないグループへの切り替えは説明を返し、その注意事項を編集プロジェクトにも保存します。深度のない写真で完全な遮蔽を保証することはできません。

## 表示と選択・色編集

`SceneRenderer` は `MeshDescriptor` と `MeshResource` を使って表示メッシュを生成します。ワイヤーフレームはデバッグ表示だけに依存せず、制限付きの実エッジリボンメッシュとして描画します。写真付き面はUnlitMaterial、写真なしの面はPBRマテリアルです。

`EditorViewContainer` は非ARのRealityKitシーンにPerspectiveCameraとライトを置き、回転・ズーム・視点移動を実装します。`MeshRaycaster` はARViewから得たレイを実際の三角形と交差判定し、最も近い部分を選択します。凸包の当たり判定で離れた領域の間の空間を選択することを避けています。

写真の色調整はCore Imageの色コントロールと乗算着色を使い、変更前のJPEGを保持します。表示と書き出しには同じJPEG調整関数を使用します。Undo履歴は色調整の差分として保持し、スライダーの連続操作をまとめます。元画像・カメラ姿勢を使った再投影UIや、AIによる家具インスタンス分割は含みません。

## 保存・USDZ

`ScanLibrary` は `.questscan` のJSONを原子的に保存します。形式バージョン、UUID、ファイルの大きさ、配列サイズ、有限値、三角形インデックス、法線、UV、色設定を検査します。外部パス、パストラバーサル、最終ファイルのシンボリックリンク、IDの不一致を拒否します。Appleの `/var` と `/private/var` の正規パス差を許容します。

`USDZExporter` はUSDの読みやすいUSDAレイヤーと調整済みJPEGを組み立てます。`StoredZIP` は非圧縮、64バイトアラインメント、CRC32、先頭USDレイヤー、中央ディレクトリを持つUSDZを生成します。USDPreviewSurface、UVリーダー、パッケージ内画像、メートル単位、Y-up、マテリアルバインドを記録します。これはModelIOの端末ごとの書き出し拡張子対応に依存しない実装です。

カメラ・スキャンデータに対するネットワーク処理はありません。共有は `UIActivityViewController` にローカルUSDZのURLを渡し、利用者の選択によって行います。App Store用署名、Apple開発者チームID、提出手続きは別途必要です。
