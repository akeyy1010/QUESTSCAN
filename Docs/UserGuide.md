# QUESTSCANの使い方

## Swift Playgroundsで開く

GitHubの `main` からソースを取得するか、配布ZIPをダウンロードします。ZIPを展開すると `QUESTSCAN.swiftpm` というフォルダが現れます。このフォルダの名前・拡張子・内部構成を変えずに、iPadの「ファイル」へ移動し、Swift Playgroundsで開いて実行します。`Package.swift` 単体を開くのではなく、`.swiftpm` パッケージ全体を開いてください。

実行にはiOS／iPadOS 16以降と、それに対応するSwift Playgrounds 4.x以降が必要です。MacではSwift Playgroundsまたは対応するXcodeでソースを開けますが、ARKitの空間スキャンは対応するiPad／iPhone実機で確認してください。macOSネイティブ用の別アプリではありません。iPhoneにSwift Playgroundsアプリはないため、iPhoneへのインストールはMac上のXcodeと署名設定を利用します。

アプリをApp Storeへ提出するためのチームID・プロビジョニング・署名は含めていません。個人の開発チーム設定は、利用するAppleアカウントに合わせてPlaygroundsまたはXcodeで設定してください。

## 最初にデモを試す

ホームから「デモルーム」を開くと、床・ソファ・テーブル・窓・植物などを備えた、プログラムで生成された部屋を表示します。カメラ権限は不要です。これは実際のスキャン結果ではなく、撮影枚数やスキャン率を架空の数字で埋めることもありません。

3D画面は1本指のドラッグで回転、ピンチで拡大縮小、2本指のドラッグで視点中心を移動できます。ダブルタップで全体が見える位置へ戻ります。モデルまたは部分一覧から対象を選び、色・着色の強さ・明るさ・コントラスト・彩度を変更します。「元に戻す」「やり直す」も使えます。

ホーム画面右上の歯車から「スキャン設定」を開きます。設定を変更したら「設定を保存」を押してください。設定はアプリ内に保存され、次回起動後も引き継がれます。

## スキャン設定

「自動撮影」は、ARの位置追跡状態とカメラの移動・回転に応じて写真を記録します。オフの場合は撮影ボタンから手動で記録します。「自動撮影の感度」は3段階です。**控えめ**は移動・角度の変化が大きいときだけ撮影し、間隔を約2秒空けます。**標準**は約1.2秒、**高感度**は小さな変化にも反応して最短約0.7秒間隔になります。追跡が不安定なときはどの設定でも写真を保留し、低電力モードでは最短間隔を約2秒に制限します。高感度は似た写真が増え、容量や処理時間が増加することがあります。

「写真の最大枚数」は8・16・24・32・64・128・256・512・1,000枚から選べます。手動と自動の両方が同じ上限に含まれ、初期設定は1,000枚です。以前の既定上限32枚は初回起動時に1,000枚へ移行しますが、利用者が明示的に選んだ32枚設定は保持されます。「写真の解像度」は長辺960pxまたは1,280px、「JPEGの画質」は節約・標準・高画質から選びます。

1,000枚など32枚を超える設定では、端末メモリを抑えるため、撮影写真を最大640px・1枚180KB以内、LiDAR深度を最大64pxに自動縮小します。選択したJPEG画質と解像度を可能な限り優先し、指定サイズに収まらない写真だけ段階的に圧縮・縮小します。このモードでの上限は写真データ約180MBと深度データ最大約16MB（ほかにアプリ管理分が必要）を見込む設計です。3D化では投影計算を制限するため、撮影写真は保持・カウントしたうえで、最大128枚を時間順に均等選択してテクスチャ投影します。低電力モードでは撮影間隔を延ばします。

「形状の最大三角形数」は20,000・40,000・60,000面、「スキャン中にメッシュ線を表示」はオン／オフで設定します。上限を超えた面は均等に間引かれる場合があります。形状の精度を上げると、メモリ・処理時間・発熱が増えやすくなります。「初期設定に戻す」で既定値に戻してから保存できます。

## 実際の空間をスキャンする

ホームのスキャン開始ボタンを押し、カメラの使用を許可します。LiDAR対応端末ではARKitの空間メッシュを取得します。分類を利用できる場合は、床・壁・天井・テーブル・椅子等の分類情報も保持します。端末や環境によって分類が不明になることは正常です。

非LiDAR端末では、ARKitが検出した床や壁等の平面を三角形へ変換して取得します。写真の自動取得・平面への投影・色編集・USDZ書き出しは利用できますが、家具の曲面や細かい立体形状を復元するものではありません。

明るい場所で、模様のある床・壁にカメラを向け、ゆっくり移動してください。ひとつの場所で回転するだけでなく、少し横へ移動して同じ面を別角度から撮影すると投影品質が上がります。鏡・ガラス・光沢面・無地の壁・暗所は苦手です。人が動いている場所や高速移動も避けてください。

自動撮影は、位置または角度の変化・設定した感度と間隔・ARの追跡状態を条件に行います。手動撮影も可能です。写真の上限は設定で最大1,000枚です。上限後も形状の更新は続きますが、新しい写真は追加されません。1,000枚近くの撮影には長時間を要します。広い場所は短い単位に分けて撮影してください。

画面のカバー率は、**検出済みの面に写真を投影できる割合の推定**です。部屋全体の完成率ではありません。新しい未撮影の面が見つかると割合が下がることもあります。生成後のカバー率は、表示用に残した三角形のうち実際に写真が割り当てられた面の面積割合です。スキャン中の推定値とは少し異なる場合があります。

アプリをバックグラウンドへ移すとスキャンは一時停止します。戻ったら画面の再開ボタンを押します。座標の連続性を保つため、休止中に端末を遠くへ移動しないでください。追跡が回復しない場合は、そのスキャンを終了するか、新たに開始してください。

## 生成・編集

スキャンを終了すると、メッシュに各写真の撮影位置・内部パラメータを使って写真を投影します。LiDAR深度を利用できる写真では、他の物体に隠れている面への不適切な投影も抑制します。写真がない／見えていない／投影条件に合わない面は、写真のないメッシュとして保持します。

選択単位は「元のアンカー・面の分類・使用写真」で分割した部分メッシュです。同じ家具が複数の部分に分かれる場合があります。AIによる家具の完全なインスタンス分割や、家具を自動で独立モデルに切り出す機能ではありません。写真の切り替わりには継ぎ目が残る場合があります。

色調整は元画像を破壊せず保持し、表示・USDZ書き出し時に反映します。編集された写真が異なる明るさになるため、隣接する未編集部分との境界も目立つ場合があります。写真のない面では彩度を変えてもグレーのベースそのものには効果がありません。色と着色の強さを使ってください。

## 保存・共有

生成したスキャンは端末内へ自動保存します。追加の編集は保存ボタンで保存できます。ホームへ戻る操作でも現在のドキュメントを保存します。保存一覧から再度開いて編集できます。削除する場合は確認ダイアログを経由します。

ネイティブ編集データはアプリの `Documents/QUESTSCAN` に `.questscan` ファイルとして保存します。アプリ削除時にはこのデータも失われる可能性があります。必要なファイルは「ファイル」アプリ等で別の場所へコピーして保管してください。現在、他の場所からの `.questscan` インポートUIは実装していません。バックアップの復元は同じアプリの書類フォルダへ戻す必要があります。

「USDZ書き出し」を押すと、写真・色調整・形状を含む `.usdz` を生成し、iOSの共有シートを開きます。「ファイルに保存」やAirDrop等を選べます。共有先のアプリによって対応形式が異なります。USDZは3D閲覧・共有用で、アプリのUndo履歴や元の編集プロジェクトを保持するものではありません。

カメラ画像・深度・スキャンデータは端末内で処理します。アプリ自身によるクラウド送信、広告、アナリティクス、会員登録はありません。共有シートで利用者が選んだ送信先や保存先の挙動は、そのサービスの設定に従います。撮影には人物・書類・家の内部が写り込む可能性があるため、共有前に内容を確認してください。

## 問題が起きたとき

カメラ権限を拒否した場合は「設定」からQUESTSCANのカメラを許可して再度開始します。面を検出できない場合は、照明を改善し、床や壁の模様のある部分をゆっくり撮影してください。対応しない端末やシミュレータではデモルームをご利用ください。

メモリと描画負荷を抑えるため、取得・表示・投影には面数、アンカー数、写真数、グループ数の上限があります。上限に達した場合は均等サンプリングや写真のないメッシュへ切り替え、必要に応じて画面に説明を表示します。計測器としての精度保証、完全に閉じたメッシュ、製造・施工に使える寸法精度は保証しません。
