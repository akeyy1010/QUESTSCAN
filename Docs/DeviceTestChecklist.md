# 実機受け入れテスト

Apple SDKの型チェックとUSDZ構造テストだけでは、実カメラ・LiDAR・GPU・共有先アプリの動作までは確認できません。以下は実機確認用の項目です。未実施の項目を「合格」として扱わないでください。

## 起動・権限

- [ ] iPadのSwift PlaygroundsでQUESTSCAN.swiftpmを開き、ビルド・起動する。
- [ ] iOS 16相当の利用APIに未対応のものがないことを実際の対応端末で確認する。
- [ ] iPhoneはXcodeから署名して実機へインストールし、縦画面・横画面を確認する。
- [ ] カメラ許可・拒否・設定からの再許可をそれぞれ試す。
- [ ] カメラを拒否してもデモが開ける。
- [ ] iPadのSplit View、小さいiPhone、横画面でボタンが画面外へ出ない。
- [ ] Dynamic Type、VoiceOver、Reduce Motionで主要操作ができる。

## ARスキャン

- [ ] LiDAR端末で床・壁・家具の実メッシュとネオンワイヤーが一致する。
- [ ] 非LiDAR端末では平面モードと表示され、家具の立体復元と誤認しない。
- [ ] 自動撮影が停止した端末では増えず、移動時に増える。
- [ ] 手動撮影が追跡良好時に成功する。
- [ ] 設定で最大1,000枚を選ぶと撮影上限が変わり、以後も形状更新は続く。
- [ ] 高枚数モードで画像が640px／180KB以内、深度が64px以内に抑えられることを確認する。
- [ ] 1,000枚近いスキャンでメモリ警告・強制終了・過熱がないか、低電力モードも含めて検証する。
- [ ] 128枚超の撮影から、3D化が時間順の均等サンプルを使い、警告表示とカバー率が適切であることを確認する。
- [ ] 新しい未観測面の追加でカバー率が変化し、100%を完了保証として扱わない。
- [ ] 暗所・無地面・高速移動時に追跡ガイドが表示される。
- [ ] 一時停止・再開で元の座標と取得データを保持する。
- [ ] バックグラウンド移行で一時停止し、復帰時は明示的に再開できる。
- [ ] AR割り込み・セッションエラー時に説明が出て、破損状態で処理を続けない。
- [ ] スキャン中止でカメラが停止し、不要な写真が書類へ保存されない。
- [ ] 面検出ゼロで終了した際、再開可能な説明が出る。

## 写真投影・編集

- [ ] 生のカメラ画像の縦横向き・UVの上下が一致する。縦／横端末両方で試す。
- [ ] LiDAR深度による遮蔽判定で、手前の家具が奥の壁へ貼り付く症状を軽減する。
- [ ] 未投影面が欠落せず写真のない形状として残る。
- [ ] タップと部分一覧で選択し、選択ハイライトが表示される。
- [ ] 回転・ズーム・2本指移動・ダブルタップができる。
- [ ] 色・着色強度・明るさ・コントラスト・彩度が選択部分に反映される。
- [ ] Undo／Redo／リセットが機能し、視点が不要にリセットされない。
- [ ] 大きいスキャンと連続スライダー操作でメモリ使用と反応速度を確認する。

## 保存・書き出し

- [ ] スキャンが自動保存され、再起動後も一覧から開ける。
- [ ] 編集後の保存とホームへ戻る保存が反映される。
- [ ] 削除の取消と確定がそれぞれ機能する。
- [ ] デモ・写真ありスキャン・写真なしスキャンをそれぞれUSDZへ書き出す。
- [ ] iPadの共有シートがクラッシュせず「ファイルに保存」できる。
- [ ] iOS Quick Lookで形状・写真・編集色・単位・向きを確認する。
- [ ] Finder／Reality Composer／他のUSD対応ビューアでも開ける。
- [ ] 保存容量不足・読み取り不正・壊れたファイルが安全にエラーになる。

このチェックリストを完了していない段階では、実機動作検証済み・App Store提出準備完了とは表現しません。
